# Helix

> A modular handheld companion built on the ESP32-S3.

Helix is an open-source embedded project that explores building a portable, battery-powered device from scratch. The project started as an offline music player and will evolve over time into a general-purpose handheld companion.

The focus is on learning embedded systems, hardware design, audio processing, and UI development through incremental releases.
